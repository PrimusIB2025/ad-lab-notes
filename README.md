# Active Directory & Samba AD DC Lab Notes

This repository contains my personal notes, enumeration scripts, and attack methodologies developed during my practical labs and infrastructure security assessments.

## 📂 Repository Structure (In Progress)

*   **`01_Enumeration/`** — Nmap scanning, NetExec (nxc), LDAP (ldapsearch), and SNMP (snmpwalk) commands.
*   **`02_AD_Attacks/`** — Notes on Kerberoasting, AS-REP Roasting, NTLM Relay, Coercion, Zerologon (CVE-2020-1472), and NoPac.
*   **`03_Samba_AD_DC/`** — Specific research, script debugging, and ACL analysis for Samba environments.
*   **`04_Case_Studies/`** — Methodologies and findings from authorized network device (MFP, NAS) assessments.

## 🛠️ Core Toolkit
- **Recon:** Nmap, NetExec (nxc), ldapsearch, snmpwalk, dig
- **AD/Samba:** BloodHound, Impacket, samba-tool
- **Analysis:** Python (script reading/debugging), Browser DevTools (HAR, SOAP/XML)

## ⚠️ Disclaimer
All research, testing, and script execution documented in this repository were conducted in authorized lab environments (Hack The Box, personal labs) or during authorized security assessments.
